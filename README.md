# Big Bazaar Shadnagar - Landing Page

A premium, high-conversion landing page designed for Big Bazaar in Shadnagar. This project is a fully responsive, vanilla HTML/CSS/JS web application optimized for fast loading and lead generation.

## 🌟 Features

* **Premium Design System:** Built with a Deep Navy Blue (`#001F3F`) and Gold (`#D4AF37`) color palette.
* **Lead Generation:** Includes a smart, zero-cost WhatsApp Chatbot to collect leads without a backend.
* **Fully Responsive:** Mobile-first approach ensuring a perfect layout across all devices.
* **Performance Optimized:** No heavy frameworks (No React, Tailwind, or Bootstrap). 100% Vanilla HTML, CSS, and JS. Images and maps are lazy-loaded.
* **Multi-Page Architecture:** Includes sub-pages for specific categories (`mens.html`, `ladies.html`, `kids.html`).
* **SEO Ready:** Includes Meta Tags, Open Graph data for social sharing, and semantic HTML.

## 🛠️ Tech Stack

* **HTML5**
* **CSS3** (Flexbox, CSS Grid, Keyframe Animations)
* **Vanilla JavaScript** (ES6)

## 🚀 Usage

Simply open `index.html` in any modern web browser to view the site. No build process, dependencies, or local server is required for development.
